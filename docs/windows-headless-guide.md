# Инструкция: Запуск Tailchat в фоновом режиме (Headless) на Windows

Данная инструкция предназначена для настройки постоянной фоновой работы Tailchat на Windows (iRU / десктоп) через **PM2**.

В фоновом режиме Tailchat:
* Работает без открытого окна терминала.
* Держит постоянное P2P-соединение через Tailscale.
* Принимает сообщения и файлы в папку загрузок.
* Присылает всплывающие системные уведомления Windows (в правом нижнем углу).
* Записывает историю диалога в `~/.tailchat/`.
* Отрабатывает напоминания и будильники (`/remind` и `@tailik`).

---

## Шаг 1. Обновление репозитория

Откройте командную строку (**CMD** или **PowerShell**) и перейдите в папку с Tailchat:

```cmd
cd C:\path\to\tailchat
git pull
npm install
```

> **Важно:** Убедитесь, что версия в `package.json` не ниже `0.57.43`.

---

## Шаг 2. Установка PM2

Если менеджер процессов PM2 ещё не установлен глобально:

```cmd
npm install -g pm2
```

---

## Шаг 3. Первый запуск фонового демона

Укажите имя пира (собеседника в Tailscale, например `macOS` или `macbook-pro`):

### Вариант A. Через файл конфигурации (рекомендуется):
```cmd
pm2 start ecosystem.config.cjs -- macOS --headless
```

### Вариант B. Напрямую через скрипт:
```cmd
pm2 start bin\tailchat.js --name "tailchat" -- macOS --headless
```

---

## Шаг 4. Проверка статуса и просмотр логов

1. **Проверьте статус службы:**
   ```cmd
   pm2 status
   ```
   В таблице колонка `status` должна показывать **`online`** (зеленым цветом).

2. **Просмотр логов в реальном времени:**
   ```cmd
   pm2 logs tailchat
   ```
   В логах отобразятся события подключения:
   ```text
   [status] connecting…
   * listening on 100.x.y.z:4747
   [status] online
   * Connected to macOS
   ```
   Для выхода из режима просмотра логов нажмите `Ctrl + C` (сам процесс продолжит работать в фоне).

---

## Шаг 5. Настройка автозапуска при загрузке Windows

Чтобы Tailchat автоматически поднимался при старте системы:

1. Сохраните текущий список активных процессов:
   ```cmd
   pm2 save
   ```

2. Установите обертку службы Windows для PM2 (выполните в PowerShell от имени Администратора):
   ```cmd
   npm install -g pm2-windows-service
   pm2-service-install
   ```
   *(На все вопросы установщика можно нажимать Enter для значений по умолчанию)*.

   *Альтернативный простой вариант без службы:*
   Нажмите `Win + R`, введите `shell:startup` и создайте там bat-файл `start-tailchat.bat` со строкой:
   ```cmd
   pm2 resurrect
   ```

---

## Шаг 6. Команды повседневного управления

| Задача | Команда |
|---|---|
| Посмотреть статус | `pm2 status` |
| Посмотреть живые логи | `pm2 logs tailchat` |
| Перезапустить службу | `pm2 restart tailchat` |
| Остановить службу | `pm2 stop tailchat` |
| Запустить после остановки | `pm2 start tailchat` |
| Полностью удалить из PM2 | `pm2 delete tailchat` |

---

## Шаг 7. Переключение между фоновым режимом и графическим TUI

Если вам нужно открыть полноценный графический интерфейс чата в окне терминала:

1. Приостановите фоновую службу:
   ```cmd
   pm2 stop tailchat
   ```
2. Запустите чат в интерактивном режиме:
   ```cmd
   tailchat macOS
   ```
3. Когда закончите общение и закроете окно чата, верните фоновый режим:
   ```cmd
   pm2 start tailchat
   ```

---

## Решение возможных проблем на Windows

1. **`unknown flag: --headless`**  
   Вы находитесь на старой версии. Выполните `git pull` и `npm install`.

2. **`File ecosystem.config.cjs not found`**  
   Убедитесь, что вы находитесь в корневой папке проекта (`cd C:\...\tailchat`), где лежит этот файл.

3. **Служба в статусе `errored` (циклический перезапуск)**  
   Сбросьте список процессов и запустите заново:
   ```cmd
   pm2 delete all
   pm2 start ecosystem.config.cjs -- macOS --headless
   pm2 save
   ```

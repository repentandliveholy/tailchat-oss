# Tailchat на Windows: варианты

Коротко: рабочий Tailchat на Windows есть уже сегодня — это PWA
`https://repentandliveholy.org/tailchat/`. Ниже — что это даёт, чего не даёт,
и во что имеет смысл вкладываться дальше.

## 0. Что уже работает (нулевая стоимость)

Edge/Chrome → «Установить приложение». Получаем отдельное окно без адресной
строки, иконку в меню «Пуск» и на панели задач, Web Push (Windows показывает
их в «Центре уведомлений»), офлайн-оболочку из Service Worker
(`web/cloud/sw.js`) и значок непрочитанного на иконке.

Чего нет: автозапуск при входе в систему, работа при закрытом окне,
глобальные горячие клавиши, значок в системном трее, интеграция с файловой
системой сверх обычного диалога загрузки.

## 1. PWA + ярлык автозапуска (1 день)

`--app=https://…/tailchat/` в ярлыке в папке `shell:startup`, плюс
`--start-minimized`. Закрывает главный пробел PWA — «приходит только когда
окно открыто» — не добавляя ни строчки нового кода на поддержку. Уведомления
работают, пока окно свёрнуто.

Ограничение: это всё ещё окно браузера, а не процесс в трее; пользователь
может его закрыть и снова остаться без уведомлений.

## 2. Tauri-обёртка (2–4 дня, рекомендуемый вариант)

Rust-хост + системный WebView2 (уже есть в каждой Windows 10/11), внутрь
загружается тот же `web/cloud`. Даёт ровно то, чего не хватает PWA: иконку в
трее, автозапуск через реестр, нативные уведомления, единый `.msi`/`.exe`
инсталлятор, единый код с вебом. Бинарь ~5–10 МБ (против ~150 МБ у Electron),
обновляется тем же деплоем, что и веб, — обёртка тонкая и версионируется
отдельно и редко.

Стоимость: новый CI-таргет (сборка под Windows требует Windows-раннера или
кросс-сборки), подпись кода (иначе SmartScreen ругается на первый запуск),
и ещё один артефакт, который надо не забывать выкладывать.

## 3. Electron (не рекомендуется)

Те же возможности, что у Tauri, но ~150 МБ на установку, отдельный Chromium в
памяти и своя цепочка обновлений безопасности. Оправдан, только если
понадобится API, которого нет в WebView2, — сейчас такого нет.

## 4. Нативный клиент (WinUI 3 / Avalonia) — не сейчас

Полный порт UI на C#/.NET. Это второй Android по объёму работ (там ~11 тыс.
строк Compose) и третья реализация протокола. Оправдано только если Windows
станет основной платформой.

## 5. Терминальный клиент в WSL/Windows Terminal (0 дней)

`src/cli.js` работает под Node на Windows и полноценно — в WSL. Для
разработчика это уже готовый Tailchat: тот же облачный аккаунт, те же
сообщения. Ограничение — Blessed и wide-chars поведение в `cmd.exe`;
Windows Terminal обязателен.

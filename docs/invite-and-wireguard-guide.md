# Инструкция: Приглашение гостей (Инвайт-скрипт) и работа через WireGuard

---

## 1. Автоматический инвайт-скрипт (`install-guest.sh`)

Для быстрого подключения нового человека к вашему Tailchat в репозитории подготовлен универсальный скрипт автоматической установки.

### Как пригласить человека (в 1 команду)

1. В админ-панели Tailscale сгенерируйте ссылку приглашения на ваш Mac:
   * Меню **Machines** $\to$ найдите `macbook-pro` $\to$ нажмите `...` $\to$ **Share…** $\to$ скопируйте ссылку инвайта (например, `https://login.tailscale.com/admin/invite/abc123xyz`).
2. Отправьте гостю одну строчку для вставки в терминал (macOS / Linux / Android Termux / Git Bash на Windows):

```bash
curl -fsSL https://raw.githubusercontent.com/repentandliveholy/tailchat-oss/main/install-guest.sh | bash -s -- "https://login.tailscale.com/admin/invite/abc123xyz" macbook-pro
```

### Что скрипт делает на машине гостя автоматически:
1. **Определяет операционную систему** (macOS, Ubuntu/Debian/Fedora/Arch Linux, Android Termux, Windows).
2. **Проверяет и устанавливает зависимости:**
   * Проверяет наличие `Node.js` ($\ge 18$) и `git`. Если их нет — устанавливает через системный пакетный менеджер (`brew`, `apt`, `dnf`, `pacman`, `pkg`).
3. **Открывает инвайт в браузере:**
   * Автоматически открывает ссылку в браузере по умолчанию, чтобы гость в 1 клик вошел под своим аккаунтом Tailscale/Google/Apple.
4. **Клонирует и настраивает Tailchat:**
   * Загружает последнюю версию в `~/tailchat` и выполняет `npm install`.
5. **Создает глобальную команду `tailchat`** на `PATH` (в Termux связывает с `termux-wake-lock` лаунчером).
6. **Сразу предлагает открыть чат** и подключается к вашему `macbook-pro`.

## 2. Работа через обычный WireGuard (MikroTik / VPS) без Tailscale

Если вы и ваш собеседник подключены к одному обычному WireGuard-серверу (например, на вашем роутере MikroTik или Linux VPS):

### Как это работает:
1. **Единая виртуальная подсеть:**  
   Сервер WireGuard выдаёт клиентам внутренние IP-адреса (например, вашему Mac — `10.0.0.2`, а собеседнику — `10.0.0.3`).
2. **Сквозное шифрование:**  
   Весь трафик между клиентами шифруется протоколом WireGuard на уровне ядра ОС.
3. **Прямое соединение:**  
   * Собеседник запускает: `tailchat 10.0.0.2`
   * Вы запускаете: `tailchat 10.0.0.3`
   * Tailchat распознает приватный IP `10.0.0.x`, соединяется по TCP на порту **4747** и работает со всеми функциями (текст, файлы, голосовые сообщения, напоминания).

## 3. Ограничение доступа гостя через Tailscale ACL (порт 4747)

Чтобы гость имел доступ **строго к приложению Tailchat на вашем Mac** и не мог сканировать порты или видеть другие устройства сети (MikroTik, домашние серверы):

В админ-панели Tailscale перейдите в раздел **Access Controls** и добавьте правило:

```json
{
  "acls": [
    // Гость может отправлять пакеты ТОЛЬКО на ваш Mac и ТОЛЬКО на порт 4747:
    {
      "action": "accept",
      "src": ["guest@example.com"],
      "dst": ["macbook-pro:4747"]
    },
    // Ваш Mac может отвечать гостю ТОЛЬКО на порт 4747:
    {
      "action": "accept",
      "src": ["macbook-pro"],
      "dst": ["guest@example.com:4747"]
    }
  ]
}
```

## 4. Сравнение способов подключения

| Способ | Лимит по пользователям | Шифрование | Изоляция вашей сети |
|---|---|---|---|
| **Node Sharing (инвайт на 1 Mac)** | **Безлимитно (0 мест)** | Сквозное WireGuard | Полная изоляция Mac |
| **Гость в Tailnet с ACL (порт 4747)** | До 3 пользователей (Free) | Сквозное WireGuard | Закрыто всё, кроме порта 4747 |
| **Обычный WireGuard (MikroTik / VPS)** | Безлимитно | Сквозное WireGuard | Зависит от маршрутов WG |
| **Прямой локальный LAN / Wi-Fi** | Безлимитно | Без шифрования (открытый TCP) | Внутри домашней сети |
